### 📱 Para ver los cambios

1. **Iniciar el servidor de desarrollo:**

   ```bash
   cd frontend
   npm run dev
   ```

2. **Abrir en el navegador:**
   - URL: `http://localhost:5173`
   - O la URL que muestre el terminal

3. **Compatibilidad**: Funciona en todos los navegadores modernos

### 🔧 Personalización

Si deseas cambiar colores, edita las variables en:

```
frontend/src/index.css
```

Busca la sección `:root` y modifica:

```css
--color-primary: #tu-color-aqui;
--color-accent: #tu-acento-aqui;
```
