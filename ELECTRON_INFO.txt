npm run dist                - Crear instalador
npm run pack                - Testing (sin instalar)

🖥️  INSTALACIÓN EN NUEVA PC

1. Instalar PostgreSQL
2. Ejecutar RESEJ-Setup-1.0.0.exe
3. Ejecutar configurar-env.bat
4. Crear base de datos
5. Ejecutar migraciones: npx knex migrate:latest
6. Iniciar aplicación

Ver: POSTINSTALACION.md para detalles
